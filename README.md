# Sistem Penjualan Hasil Panen
Program ini memuat digunakan untuk mengelola data hasil panen dan proses penjualan dilengkapi fitur pendataan hasil penjualan, tampilan stok dan harga komoditas, pembaruan stok secara otomatis, serta pemberian diskon berdasarkan total pemberian.
Cara menjalankan program :
1. Pastikan Python sudah terpasang pada perangkat.
2. Clone atau download repository sistem-panen-[nama_anda].
3. Buka folder proyek melalui terminal atau Visual Studio Code.
4. Jalankan program dengan perintah:
   </> Bash
   python sistem_panen.py
5. Program akan menampilkan menu utama. Pilih menu sesuai kebutuhan, seperti melihat data panen, melakukan penjualan, melihat riwayat transaksi, atau melihat total pendapatan.
